# 公共运行基础开发说明

`core` 提供跨模块的运行机制，首期实现日志。模块只依赖标准库。项目入口配置 logger，业务模块通过模块名记录事件。

| 文件 | 职责 |
|---|---|
| `__init__.py` | 导出日志配置和运行上下文。 |
| `log/logging.py` | 配置应用、异常及访问日志，管理文件切换、保留和运行 ID。 |
| `config.toml` | 声明默认日志级别和保留期限。 |
| `README.md` | 说明日志位置、格式和排查方式。 |
| `test/log/test_logging.py` | 验证分流、上下文、UTC 日期切换与保留策略。 |
