# 产品方案

## 产品目标

将 B 站 UP 主视频自动转为结构化字幕，支持按 UP 主/系列/时间索引，为后续构建向量知识库和 AI Agent 提供数据基础。

## 核心场景

| 场景 | 描述 |
|------|------|
| 批量转录 | 一键将 UP 主数百个视频转为 SRT 字幕 |
| 系列处理 | 指定某个系列/合集单独处理 |
| 增量更新 | 定期运行，只下新视频，跳过已有 |
| 字幕索引 | 按日期、标题、播放量浏览/搜索已有字幕 |
| 数据出口 | 输出结构化数据供向量库/知识图谱消费 |

## 产品演进路线

### v0.1 (已完成)
- [x] 视频列表爬取 + DASH 音频下载
- [x] faster-whisper 本地转录 (small 模型)
- [x] 繁体→简体转换 (OpenCC)
- [x] 按 UP 主分类输出 + JSON 索引
- [x] `--list` / `--stats` / `--search` 索引查询
- [x] `--series` 系列视频处理
- [x] 二维码登录 + 凭据管理

### v0.2 (计划中)
- [ ] 结构化数据输出 (JSON + JSONL corpus)
- [ ] `--after` / `--before` 时间范围过滤
- [ ] `--video` / `--bvids` 指定单个或多个视频
- [ ] 视频元数据 CSV 导出

### v0.3 (计划中)
