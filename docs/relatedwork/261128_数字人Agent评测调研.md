# 数字人 Agent 评测调研

2026-11-27 · 相关工作调研 3/4

## 我们想问什么

- 已有系统学的是同一个人的话、很多人的行业知识，还是合成对话？评测又用谁的答案？
- 测试时能不能看见答案所在的材料？它们按真实发表顺序预测下一期，还是读完整段资料再考，或随机分组？
- 我们能否只用同一个博主前 20 期学出的知识去预测第 21 期，再用博主自己后来讲出的理由判分？这个办法有哪些真正相似的先例？
- 命中率、裁判胜率和总分到底能说明什么？怎样证明规则学得比「沿用上次观点」更好？

## 1. 结论和阅读口径

**按真实发布时间先测后吸收，适合用作 Valhalla 的主评测。** 它符合一个持续发布、领域集中、方法相对稳定的作者场景。博主后来明确说过的话可以提供标准证据，人主要核对题面的时间边界、原话和评分点。该办法能测**预判公开研究步骤**，并可独立测新一期入库后是否能被正确找回。它的结果不能直接说明作者观点客观正确或有投资收益。

Agent 评测综述和角色扮演评测综述都值得做索引。对 Valhalla，能力应拆成作者相关的判断、查证与归因、时间合规、运行成本。一个模型答对一次和整条系统能正确采集、更新与回查，是不同的评价范围。本文把公开程度分成原文、题目、标准证据和可执行评测。写法以论文和仓库为依据，第三方结果未重跑。 [LLM Agent 评测综述](https://aclanthology.org/2026.findings-acl.1330/) · [角色扮演评测综述](https://arxiv.org/abs/2502.13012)

## 3. 真正按时间，用自己收集的数据测，有哪些先例？

|---|---|---|---|
| **滚动时间验证与渐进评测** | 原时间序列或逐条到来的样本，自身真实后续值作为标签 | 每个起点仅用过去预测以后。渐进评测先记录预测，收到标签再更新，可以模拟延迟反馈 | **直接证明方法合理。** Valhalla 把数值标签换成作者后来表达的结构化理由。 [Hyndman 与 Athanasopoulos：滚动时间验证](https://otexts.com/fpp3/tscv.html) · [River 渐进评测](https://riverml.xyz/latest/api/evaluate/progressive-val-score/) |
| **LaMP** | 某个人真实的较早记录与较晚条目，任务可用后来作品标题、评分或类别 | 确实按同一个人的时间切分。近时条目作目标，较早条目作画像 | 最接近「同一个人的资料自己产生答案」。主协议是预先切分，任务不是开放式证券分析。 [时间切分 §2.2 与附录 A](https://aclanthology.org/2024.acl-long.399.pdf) |
| **Talking to Digital Twins** | 真实财经账号的历史帖子和本人真实发帖 | 按日期更新同一账号背景，实时保存。当日匹配与发帖前五日分别比较 | 最接近财经作者的后续发言验证。判据主要是方向与倾向分数，长视频里的多步理由、条件和反例可以进一步测。 [论文表 3](https://arxiv.org/html/2608.01181) |
| **MILA / Beyond Behavioral Accuracy** | 同一个真实参与者的模拟交易历史和后来实际模拟成交 | 每日收盘形成只能看过去的输入，再预测次日 | 最接近严格滚动的个人证券决定。它看行为和本人对解释的反馈，我们能核对的是公开说出的研究过程。79.82% 的近期惯性基线说明简单规则必测。 [MILA](https://arxiv.org/html/2609.15727) · [对照结果](https://arxiv.org/html/2610.26524) |
| **StreamingQA / Evo-Memory** | StreamingQA 用多年新闻及人工或生成的问题。Evo-Memory 将多个旧数据集重组为顺序任务流 | 前者按季度更新日期可见信息，后者先答当前任务再记忆反馈 | 前者给出真实日期如何做知识更新，后者给出先测后学怎么跑。两者的答案都不要求是同一个真实财经作者的后来发言。 [StreamingQA](https://proceedings.mlr.press/v162/liska22a.html) · [Evo-Memory](https://arxiv.org/html/2511.20857) |
| **ForecastBench / Live-Evo** | 先给真实尚未解决的公开事件，未来结果成为反馈 | 发答案时事件未揭晓，定期加入新题，或从刚返回的反馈更新记忆 | 适合借鉴真前瞻的提交与结果揭晓。这里比较的是实际事件，Valhalla 的主要目标是预测作者会如何分析。 [ForecastBench](https://github.com/forecastingresearch/forecastbench) · [Live-Evo](https://arxiv.org/abs/2602.02369) |

## 4. 具体到第 21 期，我们怎样做？

1. **按公开时间排资料。** 可以用前约 20% 启动，剩余按实际期数、月或季度滚动。试运行先用前 20 期和第 21 期。同日相对顺序不明时放在同一批；转载和近重复先核对最早公开时间。
2. **冻结前 20 期版本。** 测试系统只能访问由前 20 期形成的原文库、索引、案例和作者规则，以及截止点前可取得的场景资料。较晚的标题、摘要、图边、事件和缓存同样隔离。评分方单独读取第 21 期。
3. **用前期可知的事实出题。** 例如提供当时报表和价格，问优先看哪些指标、理由是什么、什么情况下改变看法。后期原话可由评审半自动提候选，再人工回听。题面不能泄漏作者结论。若从第 21 期选出将被讨论的标的，结果标作**给定标的的历史回放**，这把「猜博主会谈谁」与「猜他怎样分析」分开。
4. **先提交答案，再揭晓标准。** 各候选版本在同一资料条件下作答。逐项对照第 21 期作者的实际分析，记录命中、遗漏、归因错误和未给出依据的推断。作者没明确说的理由记成不可评分，不为他补出想法。
5. **记完分才纳入下一轮。** 第 21 期可用作第 22 期的已知历史。旧题可以检查回归，成绩不再进入未见样本得分。调参也应用到下一批，避免看过答案后追改本轮成绩。

建议分两条主测试线。**入库前预测**只测后续公开理由是否能从过去学到。**入库后回查**用另组问题测试新观点能否找到、旧日期能否回看、改判是否有前后原话。作者后来没有谈到某标的属于没有标签，须保留分母。后续可以在真实发布前固定一组候选标的和答案，报告最后有多少得到可评分公开表态。这会减少底座已经看过历史资料的问题。

## 5. 怎么判定新方法确实有效

| 对照版本 | 在相同条件下改变什么 | 能解释什么 |
|---|---|---|
| 通用模型 / 随意换成另一个作者的框架 | 移除目标作者历史，或保持事实相同而换成同领域另一作者 | 同题是否只是在测市场常识，底座是否本来知道人物或该事件 |
| 沿用最近观点 / 只读最近几期 | 取截止日前最近的同标的立场，或只给近期原文 | 作者思想较稳定时，完整模型是否胜过延续方向 |
| 普通混合 RAG | 同底座从完整的过去原文中查证，统一证据量 | 多年原文能直接解决什么，也便于定位作者框架的独立作用 |
| 静态 Skill / 静态 Skill 加 RAG | 早期生成的固定人物框架与同样的 RAG | 稳定方法能带来多少，随着新语料更新框架能再带来多少 |
| 时间记录与版本化框架 | 加有日期的观点、条件、反例和会更新的规则，分别开关 | 提升是否来自观点记忆、框架规则或新资料本身 |
| 标准证据诊断 | 回查题直接给正确证据，盲测下一期仍封存该期原话 | 区分「没找对」和「看到了仍答错」 |

- **作者一致性。** 逐项评研究步骤、理由、条件、方向和不确定性。只猜对方向得相应部分分。遇到短原话或表述相近时允许准确改写。
- **证据质量。** 分开测证据找齐、引用定位与引用是否支撑主张。公司、财报时间、单位和原话时间戳可用规则核对，理由与条件需要判读。参考 [ALCE](https://aclanthology.org/2023.emnlp-main.398/) 和 [FinLFQA](https://aclanthology.org/2025.findings-emnlp.908/)。
- **时间合规。** 检查测试快照及实际查询记录，看有没有读取未来原文、未来派生规则或事后修订的场景数据。合规与回答质量分别报告，违规运行在严格通过率里判失败。
- **清楚报告分母和成本。** 给出被抽样视频数、可评分数、缺失标签原因、不同题型的表现、配对结果、延迟、新内容入库时间和费用。同视频多题时，估计分数波动可按视频或批次重采样。开发时可从约百题起步，实际数量由人工抽样确认。
- **用人工校准开放题裁判。** 给裁判真实原话、评分项与反例，不提供候选系统身份。抽样双标，记录专家或人工分歧。裁判不确定时留待复核，评测错误单独记录。

样例含义：假设第 21 期实际先查经营现金流，再查应收；结论是观察而非立即加仓，条件是后续两季回款。系统若只说「观察，利润增长不够好」，可记方向命中、研究步骤遗漏、条件遗漏。以后评审点三项各能看见对应原话。这份评分既能告诉开发者差在哪，也能说明资料当时是否允许使用。

## 6. 这个方法的结论边界

同一博主、同一领域、长期连续，是本项目的数据优势。随机切分容易把同一事件和复盘拆到两边，也会偷用未来。按时间走更接近上线情况，但样本仍受作者选题偏好影响。本人公开原话可以作为作者一致性的依据。对没有公开说明的仓位、私下想法和正确投资决策，都需要其他证据和任务。

第一份对外实验至少回答：**完整系统是否胜过延续最近观点与普通 RAG，是否真的改善研究理由，以及它在里面有没有看到未来。** 可结合 [最接近的项目](261128_数字人Agent相关项目调研.md)、[数字人的知识组织](261128_数字人Agent组织形式调研.md) 和 [全过程追溯与可视化](261128_数字人Agent迭代追溯与可视化调研.md) 复查。
