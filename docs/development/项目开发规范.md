# 项目开发规范

## 配置与敏感信息

- **公开配置**放在所属一级模块的配置文件中，按能力分节，例如 `integration/config.toml`。这里可以保存不含凭据的 API 地址、模型 ID、超时和超参数，可提交到 Git。
- **长期凭据**保存在项目根目录的 `.env` 文件中，例如大模型 API Key。**平台临时登录会话**按平台保存在根目录的 `.sessions/` 下，例如 `.sessions/bilibili.json`。模块配置、代码、文档和日志只使用变量名或占位符。
- **Git 要求**。根目录的 `.env` 和 `.sessions/` 必须被 `.gitignore` 忽略且未被跟踪。用 `git check-ignore -- .env .sessions/bilibili.json` 检查忽略规则，用 `git ls-files -- .env .sessions/` 确认无输出。
