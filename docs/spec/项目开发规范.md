# 项目开发规范

## 配置与敏感信息

- **公开配置**放在所属一级模块的配置文件中，按能力分节，例如 `integration/config.toml`。这里可以保存不含凭据的 API 地址、模型 ID、超时和超参数，可提交到 Git。
- **敏感信息**统一保存在项目根目录的 `.env` 文件中，例如大模型 API Key、访问令牌和密码。模块配置、代码、文档和日志中只能使用变量名或占位符，例如 `DEEPSEEK_API_KEY` 和 `TOKENHUB_API_KEY`。
- **Git 要求**。根目录 `.env` 必须被 `.gitignore` 忽略且未被跟踪。用 `git check-ignore -- .env` 确认有匹配规则，用 `git ls-files -- .env` 确认无输出。禁止强制添加该文件。
